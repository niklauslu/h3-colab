> 记录纪律：跑完一条立刻补一行；会话收工（h3ctl down）后回填"会话 CU"。

## 字段说明

| 字段 | 含义 |
|---|---|
| run | 会话内序号（首条=含模型装载，续条=热跑） |
| 臂 | 配方（turbo8 / turbo4 / pika / …） |
| 端到端 | 提交→成片落地（h3ctl gen 输出） |
| 会话 CU | 本次会话总消耗（下站后读数；CLI 无余额接口时按时长估算） |
