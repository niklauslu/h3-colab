# 成本分析：自托管（Colab）vs 官方 API 单件成本对比

> 数据基准日：2026-11-20 · 全部速率/耗时为**本项目实测**（见 test-report.md / setup-log.md），
> API 价格为当日官方公开价。汇率按 $1 ≈ ¥7.2。

## 〇、换算基准：CU 的现金价值

Google Colab 官方补充包 **$9.99 / 100 CU**（[官方定价页](https://colab.research.google.com/signup)，90 天有效），
即 **1 CU ≈ $0.10 ≈ ¥0.72**。

两种口径，本文按保守的补充包价给 CU 定价：

- **补充包口径**（本文主用）：CU 按官方现金价折算，最诚实
- **订阅口径**：AI Pro（$19.99/月）含 100 CU/月，额度内边际成本 = 0——但额度有限，
  只适合"这些产出本来就在额度内"的算法

## 一、视频：H3 本地（A100）vs MiniMax API

实测速率：A100 5.4 CU/h；首条 3.5 min（含模型加载）、续出 **2.9 min/条**（768P·1344×768·124 帧≈5.17s 带音频）。
API 价：**768P ¥0.5/秒，2K ¥0.8/秒**（按生成时长计费）。

| 口径 | 计算 | CU | 单条成本 | vs API |
|---|---|---|---|---|
| **API 768P 5 秒条** | ¥0.5 × 5.17s | — | **¥2.59** | 基准 |
| API 768P 10 秒条 | ¥0.5 × 10s | — | ¥5.00 | 基准 |
| API 2K 10 秒条 | ¥0.8 × 10s | — | ¥8.00 | 基准 |
| **本地·稳态**（续出） | 5.4 CU/h × 2.9min/60 | 0.26 CU | **¥0.19** | **~13.6×** |
| **本地·摊冷启动**（2h 会话：13min 启动 + 37 条） | 10.8 CU / 37 | 0.29 CU | **¥0.21** | **~12.3×** |

**结论：本地出 768P 视频约 ¥0.2/条，是 API 的 1/12。**
100 CU 月包 ≈ 350 条 768P 视频 ≈ API 同量 ¥900+。

## 二、生图：Z-Image-Turbo 本地（T4）vs 百炼 API

实测速率：T4 **1.15 CU/h**（修正"免费"旧说法）；首张 127 s（含加载）、续出 **61 s/张**（1024²）。
API 价：百炼 z-image-turbo **$0.015/张（≈¥0.108）**（关提示词改写口径；
[qwen-image-2.1-turbo 为 $0.014/张](https://www.alibabacloud.com/help/zh/model-studio/model-pricing)）。

| 口径 | 计算 | CU | 单张成本 | vs API |
|---|---|---|---|---|
| **API z-image-turbo** | $0.015 | — | **¥0.108** | 基准 |
| **本地·稳态**（续出） | 1.15 CU/h × 61s/3600 | 0.0195 CU | **¥0.014** | **~7.7×** |
| **本地·摊冷启动**（1h 会话：8min 启动 + 51 张） | 1.15 CU / 51 | 0.0225 CU | **¥0.016** | **~6.7×** |

**结论：本地出图约 ¥0.015/张，是 API 的 1/7。**
100 CU 月包 ≈ 4500 张图 ≈ API 同量 ¥480+。

## 三、成本结构要点（为什么自托管赢）

1. **按机器时计费，不按件计费** → 产出越密集越划算；冷启动是一次性（视频 13min / 生图 8min），摊进批次
2. **真正的敌人是挂机**：生图站挂 1h = 1.15 CU ≈ 45 张图的成本 → 纪律：批量出、完事 `h3_down.sh`
3. 隐藏成本清单（自托管侧）：
   - GCS + Drive 权重存储：视频 55GB + 生图 20GB ≈ **$1.5/月**（AI Pro $10/月 GCP 点数覆盖）
   - 冷启动等待时间（非金钱，批次制工作流的一部分）
   - 高峰期 A100 可能 503（`h3_up_wait.sh` 抢位或降级 High-RAM 8.88 CU/h）

## 四、API 不可替代的场景（组合拳推荐）

| 场景 | 用哪边 |
|---|---|
| 日常批量出片/出图、反复抽卡 | **本地**（1/7 ~ 1/12 价格） |
| **2K Regenerate**（开源权重没有此能力） | 只能 API（¥0.8/秒） |
| 临时单条、不想等冷启动 | API（零启动） |
| 需要官方 SLA / 高并发保障 | API |

**推荐工作流：本地批量抽卡 → 满意的单条走 API 上 2K 精修**，两头便宜都占。
